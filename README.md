# Stormworks Meter Dot Studio

**English: [README.en.md](README.en.md)**

Stormworks 用のメーター・デジパネを、**ペイント感覚で描いて、その場で動かして、そのままLuaにできる**ブラウザツールです。

> **▶ 今すぐ使う: https://KomachiRaisu.github.io/Stormworks-Meter-Dot-Studio/**
> (インストール不要。ブラウザで開くだけです)

![スクリーンショット](docs/screenshot.png)

## なぜ作ったか

これまでのメーター作りは、こんな「四度手間」でした。

1. ベース画像を GIMP で作る
2. Lua 化ツールで変換する
3. 針だけ AI で生成する
4. PonyIDE で最終テスト・プレビューする

このツールは、**1画面で全部やります**。

## できること

- **ドット絵エディタ** … 1ピクセル単位で点を打てます。ブラシ、消しゴム、スポイト、画像のドット化に対応
- **円と目盛り** … アンチエイリアスなしの円。分割数・補助目盛り・数値ラベルを計算で自動配置
- **円弧** … レッドゾーンや、値に応じて伸びる円弧メーターに
- **針** … 値・角度の範囲を数値で指定して回転(線 / 三角)
- **バー** … 連続バー / セグメント(デジパネ風) / 動くマーカー。レッドゾーン色つき
- **文字** … 変数の値を表示。四捨五入・切り捨て・切り上げ、小数桁数、ゼロ埋めを指定可能
- **計算式** … 数値を入れる欄には変数だけでなく `speed*3`、`|value|`、`min(a,b)` のような式が使えます
- **マイナス対応** … 0基準で伸びる円弧・バー(マイナス用の色つき)、負の値でも自然に丸め・表示
- **色** … すべての要素を個別の色・不透明度に
- **レイヤー** … 表示/非表示、ロック、並べ替え(ドラッグ)、複製
- **数値変数 / Bool変数** … スライダーやON/OFFでその場で動かして確認。範囲も変更可能。Boolは「表示条件」(警告灯など)に使えます
- **Lua出力と最適化** … 重複する色指定の削除、関数の別名化、未使用変数の除去などで文字数を短縮。上限(8192 / 4096字)に対する使用量を表示
- **サンプル** … 車のメーター / 電車の運転台 / 簡易PFD

## 使い方

1. 左のツールで画面をクリック(またはドラッグ)して部品を置く
2. 右のレイヤーと詳細設定で調整。下の「変数 / プレビュー値」のスライダーで動作を確認
3. 「Lua出力」タブの **Luaをコピー** を押して、Stormworks のマイコンのスクリプトに貼り付ける

変数は `input.getNumber(CH)`(数値)/ `input.getBool(CH)`(Bool)として読み込まれます。

### ショートカット

`V` 選択 / `P` ドット / `E` 消しゴム / `I` スポイト / `O` 円 / `A` 円弧 / `R` 四角 / `L` 線 / `N` 針 / `B` バー / `T` 文字 / `Ctrl+Z` 戻す / `Ctrl+Y` やり直し / 矢印キーで1px移動(Shiftで5px)

## 既知の制限

- プレビューのフォントや円の形は、実機と数ピクセルずれることがあります
- 文字は半角英数と記号のみです(Stormworks の標準フォント)
- Stormworks 実機での動作確認は十分ではありません。不具合があれば Issue で教えてください
- 回転する背景(PFDの水平線など)や流れる目盛りには未対応です

## 動かし方・開発

ビルド不要の **`index.html` 1ファイル**です。ダウンロードしてブラウザで開くだけで動きます。編集内容はブラウザの localStorage に自動保存されます(「保存 / 読込」からJSONでも書き出せます)。
